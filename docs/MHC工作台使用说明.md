# MHC 预测工作台 · 使用说明

> 版本 1.3.0 —— 整合 NetMHCpan 4.2e / NetChop 3.1d / NetMHCstabpan 1.0 的一体化 Web 应用
> 无需命令行：双击启动，浏览器里点击即用，支持局域网多人访问。
> 1.1.0 新增：**数据库与工具**模块（GDC 突变检索 / IEDB 云端预测 / 资源清单）、**智能助手**（自然语言驱动全部工具链）。
> 1.2.0 新增：**非标准肽段处理策略**——含 B/Z/U/X 等模糊残基的文件不再整体被拦，可选择标记并预测、跳过、或删除，并支持 ⚠ 高亮标记与一键隐藏。
> 1.3.0 新增：**新抗原一键筛选**（输入突变即可自动取序列、跑三步串联、带野生型对照与 Δ排名）、**智能助手免费模型预设**（SiliconFlow / DeepSeek / 智谱 / 百炼 一键填好地址与模型名）。

## 一、这是什么

把三个专业免疫学预测工具整合进一个网页界面：

| 模式 | 对应工具 | 用途 |
|---|---|---|
| **结合预测** | NetMHCpan 4.2e | 预测肽段与 MHC 分子的结合亲和力（EL/BA 得分、%Rank、nM 亲和力） |
| **酶切预测** | NetChop 3.1d | 预测蛋白酶体切割位点（C-term 3.0 / 20S 3.0 两种模型） |
| **稳定性预测** | NetMHCstabpan 1.0 | 预测 pMHC 复合物半衰期（含亲和力综合评分） |
| **流水线** | 三者串联 | 酶切 → 候选肽 → 结合 → 稳定性，一次跑完 |
| **突变肽筛选** | NetMHCpan + stabpan | 比对野生型/突变型蛋白，只预测覆盖突变位点的肽段（新抗原筛选） |
| **新抗原一键筛选** | UniProt + 三工具 | 只填突变（如 `KRAS G12D`），自动取蛋白序列 → 酶切 → 候选肽 → 结合 + 稳定性，带野生型对照与 Δ排名 |
| **数据库与工具** | GDC / IEDB 等外部资源 | 直接检索肿瘤突变、调用云端预测、查看可用数据库与在线工具清单 |
| **智能助手** | LLM + 全部工具链 | 用自然语言下指令，助手自动查库、调工具、写报告 |

## 二、启动与停止

### 启动（双击即可）

双击 **`启动MHC工作台.bat`**（位于 `软件` 文件夹根目录）。

- 首次启动约需 10–30 秒（拉起 WSL 后端 + Windows 代理）
- 窗口显示「启动成功」后自动打开浏览器；窗口 8 秒后自动关闭，**服务在后台继续运行**
- 页面地址：`http://127.0.0.1:8080/`

### 局域网访问

启动窗口会列出局域网地址（例如 `http://192.168.115.95:8080/`），同一网络下的其他人直接在浏览器输入该地址即可使用，**无需安装任何东西**。

### 停止

双击 **`停止MHC工作台.bat`**，确认 Y 后停止全部服务。

### 查看日志 / 状态

双击 **`查看日志.bat`**：服务状态、后端日志、代理日志、实时跟踪、打开数据库目录、清空历史。

> 注意：请勿在使用期间双击「停止」，否则所有人都会断线。

## 三、八个模式怎么用

### 通用操作

1. 左侧边栏点选模式
2. 中间面板粘贴/输入序列，选择 HLA 等位基因（默认已选 HLA-A02:01）
3. 调整参数（可选）
4. 点 **开始预测**（快捷键 `Ctrl+Enter`）
5. 右侧显示结果表；可搜索、筛选（全部/强结合/弱结合/结合肽）、点列头排序
6. 点 **导出 CSV / 导出 Excel** 保存结果

### 输入格式

| 输入方式 | 格式 | 适用模式 |
|---|---|---|
| **多肽列表** | 每行一条肽序列（8–20 个氨基酸，如 `SLYNTVATL`） | 结合、稳定性 |
| **蛋白 FASTA** | `>蛋白名` 换行 `MKT...` 序列，可多条 | 全部模式（酶切/流水线**必须**用 FASTA） |
| **文件上传** | 支持 `.txt` / `.fa` / `.fasta` / `.csv` / `.xlsx` | 全部模式 |

输入框下方实时显示统计（几条肽/蛋白、总长度、有无非标准字符）。**含非标准字符（B、Z、U、J、O、X 等）时会红色提示**，并自动弹出下方「非标准肽段处理」策略框。

### 非标准肽段处理（1.2.0 新增）

过去文件里只要有一条肽含模糊残基，整个文件都会被拦下无法预测。现在由你决定怎么处理——策略框只在检测到非标准残基时出现，默认「标记并预测」：

| 策略 | 行为 | 适用场景 |
|---|---|---|
| **标记并预测**（默认） | 全部照常预测，含非标残基的肽在结果表里**琥珀色高亮 + ⚠ 角标**，结果行提示「N 行带 ⚠ 非标准标记」 | 想保留全部数据、知道哪些行仅供参考 |
| **跳过** | 只预测正常肽，被跳过的肽以**灰色占位行**列出（数值留空、注明「非标准残基 B, Z」），结果行提示「已跳过 N 条」 | 需要一份完整对照清单，明确哪些被排除 |
| **删除** | 直接剔除含非标残基的肽/蛋白，只输出干净结果，结果行提示「已移除 N 条」 | 只要可靠数值，不关心被丢掉的行 |

要点：

- 工具内部会把 B/Z/U/X 等**静默替换成 X** 后再计算，因此标记行的数值**仅供参考**，不能作为定量结论；表格里肽段显示为工具回显的 `...X` 形式。
- 结果表工具栏的筛选下拉新增 **「隐藏非标准肽段」**，一键只看干净行。
- 若**全部**输入都含非标准残基且选择了「跳过/删除」，应用会提示改用「标记并预测」或修改输入，避免空跑。
- 六种预测模式（结合 / 酶切 / 稳定性 / 流水线 / 突变筛选 / 新抗原）全部支持；FASTA 按整条蛋白处理，突变筛选连野生型对照肽含非标残基也一并标记。
- 导出的 CSV / Excel 与页面显示一致，占位行、高亮行都按当前策略保留。

### 等位基因选择

- 点等位基因框 → 搜索（支持 `A02:01`、`A0201` 两种写法）→ 点选添加
- 可同时选多个等位基因做批量预测
- 内置全部 10,491 个等位基因（HLA-A/B/C/E/G 全系）
- 快捷预设：常用等位基因一键添加

### 各模式参数

**结合预测**：输出亲和力列（BA）｜按亲和力排序｜%Rank 阈值筛选（0.5=只留强结合）

**酶切预测**：预测模型（C 端 3.0 = 默认，20S 3.0 = 蛋白酶体核心）｜切割阈值（越低切割位点越多）

**稳定性预测**：同时输出亲和力｜排序方式（稳定性/亲和力/综合）

**流水线**：切割阈值｜切割模型｜肽长（可多选 8–11）｜只在切割位点取肽（开=模拟真实提呈；关=全滑窗）｜结合筛选阈值｜最小半衰期

**突变肽筛选**：粘贴野生型蛋白序列 + 突变型序列（长度必须一致），自动识别突变位点，只预测覆盖突变的肽段。

## 三·五、数据库与工具（1.1.0 新增）

左侧边栏最后一项 **数据库与工具**（图标 ▤）。点进去是独立的两栏界面，不占用预测输入框。内有三个页签。

### 页签 1：GDC 突变检索

从 **GDC（Genomic Data Commons）** 实时拉取 TCGA 各癌种的体细胞突变。这是新抗原筛选的**上游数据源**——先在这里找到真实患者的突变，再去「突变肽筛选」模式设计突变肽。

| 控件 | 说明 |
|---|---|
| 队列 | 8 个 TCGA 项目，默认 **TCGA-PAAD（胰腺癌，185 例，24,630 条突变）** |
| 基因 | 手输基因名（如 `KRAS`）；下方 10 个**胰腺癌驱动基因芯片**可一键填入：KRAS / TP53 / SMAD4 / CDKN2A / ARID1A / KDM6A / MUC16 / TTN / RYR2 / GNAS |
| 染色体 | 可选，如 `chr12`（按位置检索时用） |
| 突变类型 | 可选过滤 |

点 **检索** 后表格给出：基因 / 氨基酸改变（如 `KRAS G12D`）/ 后果类型 / DNA 改变 / 染色体 / 起始位置 / 突变亚型 / 转录本 ID。

实测数据量（TCGA-PAAD）：

| 基因 | 突变条数 |
|---|---|
| TP53 | 79 |
| SMAD4 | 34 |
| CDKN2A | 23 |
| KRAS | 9 |

> 提示：至少指定「队列 / 基因 / 染色体」之一才能检索，全空会返回中文错误提示。

### 页签 2：IEDB 云端预测

调用 **IEDB（Immune Epitope Database）** 的在线预测服务，作为本地三工具的**交叉验证**手段。同一个肽用本地 NetMHCpan 和 IEDB 的 NetMHCpan 各跑一遍，结果一致才更可信。

- **MHC 类别**：I 类（默认，肽长 9）/ II 类（肽长 15，长度必须 ≥15）
- **预测方法**：
  - I 类 12 种：`netmhcpan_el`（默认）/ `netmhcpan_ba` / `netmhcpan` / `netmhcstabpan` / `recommended` / `consensus` / `ann` / `smm` / `smmpmbec` / `comblib_sidney2008` / `pickpocket` / `netmhccons`
  - II 类 5 种：`recommended` / `netmhciipan` / `consensus` / `comblib` / `nn_align`
- **等位基因**：手输，**必须带星号**（`HLA-A*02:01`）。应用会自动给本地写法补星号，所以 `HLA-A02:01` 也能用。支持 `HLA-DRB1*01:01` 这类 MHC-II 写法。最多 5 个。
- 单次最多 500 条肽；云端调用 10–60 秒属正常，按钮会转圈。

返回列随方法不同：`netmhcpan_el` 给 `score`（无 ic50），`netmhcpan_ba` / `netmhcpan` 给 `ic50`，`consensus` 给一大堆 `ann_ic50 / ann_rank / comblib_sidney2008_* / consensus_percentile_rank / smm_ic50 / smm_rank`。表头直接用接口返回的列名。

### 页签 3：资源清单

把设计书里提到的数据库和在线工具做成卡片墙，每张卡带状态徽标，点「打开 ↗」直接跳外链。

**7 个数据库**：GDC-PAAD（内嵌检索）/ GDC 全站 / ICGC / IEDB / IEDB Tools / UniProt / Ensembl

**9 个在线工具**（含实测可达性）：

| IEDB Immunogenicity | ✅ 在线可用 | 免疫原性预测 |
| JCAT | ✅ 在线可用 | 密码子优化（mRNA 疫苗序列设计） |
| ORFfinder | ✅ 在线可用 | 开放阅读框查找 |
| Vaxijen | ⚠ 403 | 需注册登录 |
| ToxinPred | ⚠ 不可达 | 站点迁移中 |

### 与预测模式的联动

资源清单里 **GDC-PAAD** 卡片有「在此检索突变」按钮，**IEDB Tools** 卡片有「在此调用预测」按钮，点一下直接跳到对应页签，不用来回找。

**GDC 检索完成后**，结果表上方会出现 **「一键导入新抗原筛选 →」** 按钮（仅在本次检索含错义突变时出现，按钮旁会写明可导入几条）。点它工作台会：

1. 过滤出 `consequence_type` 含 missense、且 `aa_change` 形如 `G12D` 的记录，去重后最多取 50 条；
2. 自动切到「新抗原一键筛选」模式，把 `基因 突变` 逐行填进突变列表；
3. 之后点「预览蛋白与候选肽」即可看 UniProt 条目与候选肽，点「开始预测」跑完整三步串联。

典型工作流（全部在工作台内完成，不需要复制粘贴序列）：

```
数据库与工具 → GDC 检索 KRAS（拿到 9 条真实突变）
   ↓ 点「一键导入新抗原筛选 →」
新抗原一键筛选：自动取 UniProt P01116、构造突变肽、选 HLA 等位基因
   ↓ 点「开始预测」
自动跑完 UniProt → NetChop → NetMHCpan → NetMHCstabpan 五步
   ↓ 想交叉验证
数据库与工具 → IEDB 云端预测，同一条肽再跑一遍
```

## 三·六、新抗原一键筛选

> 这是最省事的一条路径：**只需要知道突变名**，不用自己找蛋白序列。

### 输入

在「突变列表」框里每行写一个突变，支持四种写法（自动识别）：

```
KRAS G12D
TP53 R175H
KRAS p.G12D
KRAS:G12V
SMAD4 p.Arg361Cys
```

点 **「预览蛋白与候选肽」** 可先确认：每条突变对应哪个 UniProt 条目（如 `KRAS(P01116, 189aa)`）、切出多少条候选肽。确认无误再点「开始预测」。

也可以点 **「从 GDC 导入」**：直接在 TCGA-PAAD（胰腺癌）里检索 KRAS/TP53 等基因的真实突变，勾选后一键填入。（等价的另一条路径：先在「数据库与工具 → GDC 突变检索」查好，再点结果表上方的「一键导入新抗原筛选 →」。）

### 流程（自动跑完五步）

| 步骤 | 做什么 | 显示 |
|---|---|---|
| 1. UniProt | 按基因名取规范蛋白序列（人类优先，结果缓存） | 基因 / 登录号 / 长度 |
| 2. NetChop | 对**突变后的蛋白**预测蛋白酶体切割位点 | 切割位点数 |
| 3. 候选肽 | 突变位点前后滑窗，只保留覆盖突变位点的肽 | 候选肽条数 |
| 4. NetMHCpan | 突变肽 + 野生型对照肽一起预测 | 结合肽条数 |
| 5. NetMHCstabpan | 对结合肽算半衰期与综合得分 | 最终行数 |

### 结果列

| 列 | 含义 |
|---|---|
| 基因 / 突变 | 来源基因与突变写法（如 `KRAS G12V`） |
| 肽起点 | 肽在蛋白里的起始位置 |
| 突变肽 / 野生型肽 | 突变型序列 vs 原序列（对照） |
| HLA / EL 排名% / 亲和力 nM / 结合 | 同结合预测 |
| 野生型排名% / 野生型亲和力 | 同一条肽在野生型里的表现 |
| **Δ排名** | 野生型排名 − 突变型排名，**越大说明突变越"制造"了新的结合能力** |
| 切割位点 / 切割概率 | 该肽 C 端是否落在 NetChop 判定的切割位点 |
| 半衰期 h / 稳定性排名% / 综合排名% | 同稳定性预测 |

### 判读要点

- **Δ排名 > 0 且突变型 `<= SB`** 才是理想的新抗原候选（突变让它变成了强结合，而原本不结合）。
- **KRAS G12D 对 HLA-A\*02:01 是非结合的**——这是生物学事实，不是软件问题。KRAS 12 位点应优先用 **HLA-A\*11:01**（`VVGAVGVGK`，排名 0.172，SB）或 **HLA-A\*03:01**。
- 肽长建议同时选 9 和 10（MHC-I 常见长度），覆盖更全。
- 参数「只在切割位点取肽」默认**关闭**（突变位点前后全滑窗），打开后只保留 C 端在切割位点 ±1 的肽，候选更少但更接近真实呈递。

### 实测参考（TCGA-PAAD 真实突变）

8 个真实 KRAS 错义突变（Y157C / Q61H / Q61R / G12D / G12V / G12R / G12S / G12C）× 6 个 HLA（A\*02:01、A\*11:01、A\*24:02、B\*07:02、B\*08:01、C\*07:02）：

| 指标 | 结果 |
|---|---|
| 耗时 | 6.1 s |
| 候选肽 | 152 条 |
| 结果行 | 23 行（7 SB + 16 WB） |
| Top1 | `KRAS G12V / VVGAVGVGK / HLA-A*11:01 / EL 0.172% / 112.3 nM / SB / 半衰期 4.46 h / 综合 0.51%` |
| 突变特异肽 | 10 条，如 `GARGVGKSAL`（HLA-B\*07:02，突变型 EL 0.447% vs 野生型 2.85%，Δ +2.40） |

> 若只想看「突变制造出来的新结合」，把参数「只要突变特异肽」打开：只保留 Δ排名 > 0 且野生型本身不结合的行。

## 三·七、智能助手（Agent）

左侧边栏最后一项 **智能助手**（图标 🧬）。它把前面六个模式的能力串成一句话就能驱动的工作流：你说要做什么，它自己决定查哪个库、调哪个工具、要不要接着做下一步。

### 首次使用：配置模型

助手需要一个 OpenAI 兼容的大模型 API。点开配置框会看到「快速选择（免费模型）」下拉——**选中后 Base URL 与模型名自动填好**，只需再粘 API Key：

| 预设 | Base URL | 模型名 | 说明 |
|---|---|---|---|
| SiliconFlow 免费 · Qwen2.5-7B | `https://api.siliconflow.cn/v1` | `Qwen/Qwen2.5-7B-Instruct` | 注册送额度，国内直连 |
| SiliconFlow · DeepSeek-V3 | `https://api.siliconflow.cn/v1` | `deepseek-ai/DeepSeek-V3` | 同上，能力更强 |
| DeepSeek 官方 | `https://api.deepseek.com` | `deepseek-chat` | 需充值，价格低 |
| 智谱 GLM-4-Flash（免费） | `https://open.bigmodel.cn/api/paas/v4` | `glm-4-flash` | 完全免费 |
| 阿里云百炼 Qwen（免费额度） | `https://dashscope.aliyuncs.com/compatible-mode/v1` | `qwen-plus` | 有免费额度 |

也可以不用预设，手动填三项：

| 项 | 示例 |
|---|---|
| Base URL | `https://api.deepseek.com/v1`（DeepSeek）／`https://open.bigmodel.cn/api/paas/v4`（GLM）／`https://dashscope.aliyuncs.com/compatible-mode/v1`（Qwen） |
| Model | `deepseek-chat` ／`glm-4-plus` ／`qwen-plus` |
| API Key | 你的密钥 |

保存后配置存到后端 `data/agent.sqlite3`，侧栏显示「已配置 (sk-…xxxx)」。**不配也能用**，但助手只能回答不涉及模型推理的固定问题。

### 它能调用的 9 个工具

**外部数据库（4 个）**

| 工具 | 作用 |
|---|---|
| `query_uniprot` | 按基因名/蛋白名/accession 查蛋白信息与序列（人类优先） |
| `get_protein_sequence` | 按 accession 直接取 FASTA 序列 |
| `query_clinvar` | 查 ClinVar 临床意义变异（HGVS + 临床分级） |
| `search_pubmed` | 检索 PubMed 文献（标题 + 摘要线索） |

**本地三工具（5 个）**

| 工具 | 对应模式 |
|---|---|
| `predict_binding` | 结合预测 |
| `predict_cleavage` | 酶切预测 |
| `predict_stability` | 稳定性预测 |
| `run_pipeline` | 三步串联流水线 |
| `screen_mutant` | 突变肽筛选 |

### 典型对话

```
你：帮我查一下 KRAS 的蛋白序列，然后找出它的常见致病突变，
    针对 HLA-A*02:01 做新抗原筛选。

助手：（调 query_uniprot → 拿到 KRAS 188aa 序列）
      （调 query_clinvar → 找到 G12D / G12V / G12C 等）
      （调 screen_mutant → 逐个突变做筛选）
      （汇总成 Markdown 报告：哪条突变肽 %Rank 最低、亲和力多少 nM、
        半衰期多长、值不值得做疫苗）
```

```
你：TP53 在胰腺癌里有哪些热点突变？帮我查文献支持。

助手：（调 search_pubmed + query_clinvar）
      （整理成带引用的综述段落）
```

### 行为特点

- **有界循环**：最多 12 轮工具调用，超了自动收敛总结，不会无限打转
- **错误当数据**：工具失败时返回 `{"error": ...}`，助手会向你解释哪里出问题，而不是崩掉
- **流式输出**：回答边生成边显示，工具调用过程实时可见（「正在查询 UniProt…」）
- **会话保存**：每次对话存进 `data/agent.sqlite3`，可回看历史会话；每次请求带最近 24 条消息做上下文

### 注意

- 助手调用本地三工具时会占用后端，大任务期间别同时手动提交预测
- 外部库（UniProt/ClinVar/PubMed）依赖外网，国内访问偶发超时；助手会把失败原因告诉你
- API Key 明文存在 WSL 内的 SQLite，多人共用同一台机器时注意

## 四、结果怎么看

### 结合预测（9 列 + 结合标签）

| 列 | 含义 |
|---|---|
| EL 得分 / EL 排名% | 展示递呈得分（越高越好）；%Rank 越低越强 |
| BA 得分 / BA 排名% | 结合亲和力得分 |
| 亲和力 nM | **最直观**：<50 强结合，50–500 弱结合，>500 不结合 |
| **SB / WB** | 强结合（%Rank<0.5，绿色）/ 弱结合（%Rank<2，黄色）标签 |

### 稳定性预测

| 列 | 含义 |
|---|---|
| 半衰期 h | pMHC 复合物半衰期（>1h 较稳定） |
| 综合得分 / 综合排名% | 结合 + 稳定性加权（默认亲和力权重 0.8） |

### 流水线

每行 = 一条走完全流程的候选肽：切割位点、切割概率、结合排名、亲和力、半衰期。步骤卡片显示各阶段数据（多少位点 → 多少候选 → 多少保留）。

### 结合预测

SB / WB 之外，含非标准残基的行带琥珀底色与 ⚠ 角标；「跳过」策略下被排除的肽显示为灰色占位行（数值留空）。用工具栏「隐藏非标准肽段」可只看干净行。

### 突变筛选

只列覆盖突变位点的肽，附「突变」列（如 `G12D`）。重点看突变肽排名显著优于野生型肽的条目——潜在的肿瘤新抗原。若参考序列含模糊残基，对应行同样会打 ⚠ 标记。

## 六、常见问题

| 现象 | 处理 |
|---|---|
| 双击启动后窗口一闪而过 | 用「查看日志.bat」→[1] 看状态；多半是 WSL 未就绪，等 30 秒再双击启动 |
| 页面打不开 | 确认没有点过「停止」；重新双击启动 |
| 局域网别人打不开 | 确认同一网段（连同一个路由器）；确认 Windows 防火墙未拦截 node.exe |
| 提示「存在长度 4 的肽」 | netMHCpan 要求肽 ≥8 aa；换 FASTA 输入让应用自动切肽 |
| 文件含 B/Z/U/X 被整体拦下 | 已修复：输入框下方会弹出「非标准肽段处理」，选标记并预测 / 跳过 / 删除即可照常运行；详见第三节 |
| 结果表出现 ⚠ 或灰色行 | ⚠ = 含非标残基仅供参考（可点「隐藏非标准肽段」过滤）；灰色 = 按「跳过」策略保留的占位行 |
| 任务一直转圈 | 大蛋白 × 多等位基因较慢；600aa × 4 等位基因约 1 秒，1000aa 以上请耐心；可点「取消」 |
| 稳定性结果亲和力列为空 | 肽长 <7 或 >20 超出 stabpan 可靠范围（应用已给出黄色警告） |
| 502 错误的网关 | 后端未启动；双击「启动」即可恢复 |
| GDC 检索一直显示「查询中…」 | GDC 官方 API 较慢，TP53 这类 79 条突变的查询要 10–30 秒；超过 60 秒再排查网络 |
| IEDB 预测失败 | 云端服务偶发排队；先确认等位基因带星号（`HLA-A*02:01`），MHC-II 序列长度 ≥15 |
| GDC 检索报「无法连接远端服务」 | 国内访问 api.gdc.cancer.gov 偶发超时，重试一次；或换用资源清单里的外链直接开网页查 |
| 新抗原模式报「无法从 UniProt 取到序列」 | 该基因名不在 UniProt reviewed 里；换成标准基因符号（如 `CDKN2A` 而非 `P16`），或在 UniProt 官网确认规范登录号后改用登录号（如 `P01116`） |
| 新抗原结果里野生型对照全为空 | 参数「含野生型对照」被关掉了；打开后会多出野生型排名/亲和力/Δ排名三列 |
| 新抗原提示「已按给定替换强制应用」 | 该基因的 UniProt 规范序列与突变位点编号不一致（异构体差异，GNAS 常见）；程序按你给的 ref→alt 强制替换，结果仍可用，但建议核对位点编号 |
| 新抗原候选肽为 0 | 突变位置太靠蛋白两端，滑窗切不出完整肽；或「只在切割位点取肽」开着但该区域无切割位点——把它关掉再跑 |
