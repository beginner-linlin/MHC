# MHC 预测工作台 · 使用说明

> 版本 1.0.0 —— 整合 NetMHCpan 4.2e / NetChop 3.1d / NetMHCstabpan 1.0 的一体化 Web 应用
> 无需命令行：双击启动，浏览器里点击即用，支持局域网多人访问。

---

## 一、这是什么

把三个专业免疫学预测工具整合进一个网页界面：

| 模式 | 对应工具 | 用途 |
|---|---|---|
| **结合预测** | NetMHCpan 4.2e | 预测肽段与 MHC 分子的结合亲和力（EL/BA 得分、%Rank、nM 亲和力） |
| **酶切预测** | NetChop 3.1d | 预测蛋白酶体切割位点（C-term 3.0 / 20S 3.0 两种模型） |
| **稳定性预测** | NetMHCstabpan 1.0 | 预测 pMHC 复合物半衰期（含亲和力综合评分） |
| **流水线** | 三者串联 | 酶切 → 候选肽 → 结合 → 稳定性，一次跑完 |
| **突变肽筛选** | NetMHCpan + stabpan | 比对野生型/突变型蛋白，只预测覆盖突变位点的肽段（新抗原筛选） |

## 二、启动与停止

### 启动（双击即可）

双击 **`启动MHC工作台.bat`**（位于 `软件` 文件夹根目录）。

- 首次启动约需 10–30 秒（拉起 WSL 后端 + Windows 代理）
- 窗口显示「启动成功」后自动打开浏览器；窗口 8 秒后自动关闭，**服务在后台继续运行**
- 页面地址：`http://127.0.0.1:8080/`

### 局域网访问

启动窗口会列出局域网地址（例如 `http://192.168.115.95:8080/`），同一网络下的其他人直接在浏览器输入该地址即可使用，**无需安装任何东西**。

### 停止

双击 **`停止MHC工作台.bat`**，确认 Y 后停止全部服务。

### 查看日志 / 状态

双击 **`查看日志.bat`**：服务状态、后端日志、代理日志、实时跟踪、打开数据库目录、清空历史。

> 注意：请勿在使用期间双击「停止」，否则所有人都会断线。

## 三、五个模式怎么用

### 通用操作

1. 左侧边栏点选模式
2. 中间面板粘贴/输入序列，选择 HLA 等位基因（默认已选 HLA-A02:01）
3. 调整参数（可选）
4. 点 **开始预测**（快捷键 `Ctrl+Enter`）
5. 右侧显示结果表；可搜索、筛选（全部/强结合/弱结合/结合肽）、点列头排序
6. 点 **导出 CSV / 导出 Excel** 保存结果

### 输入格式

| 输入方式 | 格式 | 适用模式 |
|---|---|---|
| **多肽列表** | 每行一条肽序列（8–20 个氨基酸，如 `SLYNTVATL`） | 结合、稳定性 |
| **蛋白 FASTA** | `>蛋白名` 换行 `MKT...` 序列，可多条 | 全部模式（酶切/流水线**必须**用 FASTA） |
| **文件上传** | 支持 `.txt` / `.fa` / `.fasta` / `.csv` / `.xlsx` | 全部模式 |

输入框下方实时显示统计（几条肽/蛋白、总长度、有无非标准字符）。**含非标准字符（B、Z、U 等）时会红色提示**——工具会把它们当 X 处理，结果不可靠。

### 等位基因选择

- 点等位基因框 → 搜索（支持 `A02:01`、`A0201` 两种写法）→ 点选添加
- 可同时选多个等位基因做批量预测
- 内置全部 10,491 个等位基因（HLA-A/B/C/E/G 全系）
- 快捷预设：常用等位基因一键添加

### 各模式参数

**结合预测**：输出亲和力列（BA）｜按亲和力排序｜%Rank 阈值筛选（0.5=只留强结合）

**酶切预测**：预测模型（C 端 3.0 = 默认，20S 3.0 = 蛋白酶体核心）｜切割阈值（越低切割位点越多）

**稳定性预测**：同时输出亲和力｜排序方式（稳定性/亲和力/综合）

**流水线**：切割阈值｜切割模型｜肽长（可多选 8–11）｜只在切割位点取肽（开=模拟真实提呈；关=全滑窗）｜结合筛选阈值｜最小半衰期

**突变肽筛选**：粘贴野生型蛋白序列 + 突变型序列（长度必须一致），自动识别突变位点，只预测覆盖突变的肽段。

## 四、结果怎么看

### 结合预测（9 列 + 结合标签）

| 列 | 含义 |
|---|---|
| EL 得分 / EL 排名% | 展示递呈得分（越高越好）；%Rank 越低越强 |
| BA 得分 / BA 排名% | 结合亲和力得分 |
| 亲和力 nM | **最直观**：<50 强结合，50–500 弱结合，>500 不结合 |
| **SB / WB** | 强结合（%Rank<0.5，绿色）/ 弱结合（%Rank<2，黄色）标签 |

### 稳定性预测

| 列 | 含义 |
|---|---|
| 半衰期 h | pMHC 复合物半衰期（>1h 较稳定） |
| 综合得分 / 综合排名% | 结合 + 稳定性加权（默认亲和力权重 0.8） |

### 流水线

每行 = 一条走完全流程的候选肽：切割位点、切割概率、结合排名、亲和力、半衰期。步骤卡片显示各阶段数据（多少位点 → 多少候选 → 多少保留）。

### 突变筛选

只列覆盖突变位点的肽，附「突变」列（如 `G12D`）。重点看突变肽排名显著优于野生型肽的条目——潜在的肿瘤新抗原。

- 「查看日志.bat」→ [6] 可清空全部历史

## 六、常见问题

| 现象 | 处理 |
|---|---|
| 双击启动后窗口一闪而过 | 用「查看日志.bat」→[1] 看状态；多半是 WSL 未就绪，等 30 秒再双击启动 |
| 页面打不开 | 确认没有点过「停止」；重新双击启动 |
| 局域网别人打不开 | 确认同一网段（连同一个路由器）；确认 Windows 防火墙未拦截 node.exe |
| 提示「存在长度 4 的肽」 | netMHCpan 要求肽 ≥8 aa；换 FASTA 输入让应用自动切肽 |
| 提示「非标准氨基酸」 | 序列含 B/Z/U 等模糊码，会被当 X 处理；建议清理后重跑 |
| 任务一直转圈 | 大蛋白 × 多等位基因较慢；600aa × 4 等位基因约 1 秒，1000aa 以上请耐心；可点「取消」 |
| 稳定性结果亲和力列为空 | 肽长 <7 或 >20 超出 stabpan 可靠范围（应用已给出黄色警告） |
| 502 错误的网关 | 后端未启动；双击「启动」即可恢复 |

## 七、技术架构（供维护参考）

```
浏览器（本机或局域网）
   │  http://<本机IP>:8080
   ▼
Windows 侧 Node 反向代理（C:\AI\node.exe，监听 0.0.0.0:8080，借系统现有防火墙规则）
   │  http://127.0.0.1:8008
   ▼
WSL Ubuntu-24.04 内 Flask 后端（/opt/bio/app，Python 3.12 + Flask 3.1 + SQLite）
   │  subprocess
   ▼
/opt/bio/netMHCpan-4.2 · /opt/bio/netchop-3.1 · /opt/bio/netMHCstabpan-1.0
```

- 后端源码：`软件\mhc-app\`（改代码后跑 `scripts\120_sync_static.sh` 同步到 WSL 并重启）
- 数据库：WSL 内 `/opt/bio/app/data/mhc.sqlite3`（任务历史）
- 测试套件：`mhc-app\host\browser_test.js`（浏览器 42 项）、`scripts\130_real_scenarios.sh`（真实场景 33 项）
