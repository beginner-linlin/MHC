# NetMHC 三件套使用指南

> 所有命令均已在本机 WSL 实测通过。三个工具涵盖免疫肽组学的经典三步：
> **蛋白酶体切割（NetChop）→ MHC I 类结合预测（NetMHCpan）→ 呈递稳定性/半衰期（NetMHCstabpan）**

---

## 0. 环境准备

软件装在 WSL 里，Windows 终端打开后先进入 WSL：

```powershell
wsl -d Ubuntu-24.04
```

进去后直接敲命令名即可（已在 PATH 中）：

```bash
netMHCpan --help     # 或直接 netMHCpan 看参数列表
netchop
netMHCstabpan
```

> 也可以在 PowerShell 里一步调用：
> `wsl -d Ubuntu-24.04 netMHCpan -a HLA-A02:01 -p input.pep`

**输入文件建议放在 WSL 内部目录**（如 `~/work`），放在 `/mnt/c/...` 也能读，但从 Windows 目录跑会明显更慢。

## 1. NetMHCpan 4.2e —— MHC I 类结合预测

核心工具，输入肽段或蛋白序列，输出每条肽对指定 HLA 等位基因的结合亲和力与洗脱配体得分。

### 1.1 两种输入方式

**方式 A：直接给肽段列表**（每行一条，无表头）

```bash
cat > pep.txt <<'EOF'
SLYNTVATL
GILGFVFTL
ILKEPVHGV
EOF

netMHCpan -a HLA-A02:01 -p pep.txt
```

**方式 B：给蛋白 FASTA**（自动滑窗切成 9mer）

```bash
cat > prot.fsa <<'EOF'
>sp_P01730_example_protein
MLLSVPLLLGLLGLAVGQCSVSWQPPPEKLLSEEDLLVHCSGKV
EOF

netMHCpan -a HLA-A02:01 -f prot.fsa
```

实测：27 aa 的蛋白自动切出 **36 条 9mer**，输出中 `Identity` 列显示蛋白名 `sp_P01730_examp`，方便回溯来源。

### 1.2 关键参数

| 参数 | 作用 | 说明 |
|---|---|---|
| `-a HLA-A02:01` | 指定等位基因 | **写法不带星号**；多个用逗号 `-a HLA-A02:01,HLA-A24:02` |
| `-p file` | 肽段输入 | |
| `-f file` | FASTA 输入 | 滑窗切肽 |
| `-l 9,10` | 肽段长度 | 仅 FASTA 模式有效，默认 9 |
| `-BA` | 加结合亲和力 | 多输出 `Score_BA / %Rank_BA / Aff(nM)` |
| `-s` | 按亲和力排序 | 最强结合排最前 |
| `-t 2` | 只输出 %Rank ≤ 2 的 | 即只要 binder，过滤掉弱肽 |
| `-xls -xlsfile out.xls` | 导出表格 | **实际是 tab 分隔文本**，Excel 可直接打开 |
| `-hlaseq my.fsa` | 自定义 MHC 序列 | 预测不在库里的等位基因 |
| `-listMHC` | 列出所有支持的等位基因 | 共 13039 个（HLA-A 3739 / B 4865 / C 3234） |
| `-context` | 带上下文预测 | 需 12 残基窗口，见 §1.5 |
| `-pathogen` / `-neo` | 病原体 / 新抗原微调模型 | |

### 1.3 输出怎么读

```
 Pos   MHC        Peptide    Core  ...  Identity    Score_EL  %Rank_EL  Score_BA  %Rank_BA  Aff(nM)  BindLevel
   1   HLA-A*02:01 SLYNTVATL  SLYNTVATL  PEPLIST    0.852778    0.083   0.599970   0.655    75.81   <= SB
```

| 列 | 含义 | 判读 |
|---|---|---|
| `Score_EL` | 洗脱配体得分 (0–1) | 越高越可能被呈递 |
| `%Rank_EL` | 该得分在背景肽中的百分位 | **主要判据** |
| `Aff(nM)` | 预测 IC50 亲和力 | 越低越强 |
| `BindLevel` | `<= SB` 强结合 / `<= WB` 弱结合 | `%Rank < 0.5` → SB，`< 2.0` → WB |

> **实践建议**：以 `%Rank_EL` 为准（`< 0.5` 强结合，`< 2.0` 弱结合），`Aff(nM) < 50` 视为高亲和力。

### 1.4 常用组合

```bash
# 多等位基因一次跑完（实测 3 肽 × 3 等位基因 = 9 行）
netMHCpan -a HLA-A02:01,HLA-A24:02,HLA-B07:02 -p pep.txt

# 只要强结合肽，按亲和力排序
netMHCpan -a HLA-A02:01 -p pep.txt -BA -s -t 0.5

# 导出给 Excel
netMHCpan -a HLA-A02:01 -p pep.txt -BA -xls -xlsfile result.xls
```

### 1.5 带上下文预测（`-context`）

利用肽段两侧的侧翼序列提高准确率。**输入必须带 12 个残基的上下文窗口**：

```bash
cat > ctx.txt <<'EOF'
SLYNTVATL AASLYNTVATLA
GILGFVFTL AAGILGFVFTLA
EOF

netMHCpan -p -context -a HLA-A02:01 -f ctx.txt
```

> ⚠️ **必须正好 12 个残基**（9mer 肽 + 3 个侧翼）。长度不对时程序**不报错，静默输出 0 行** —— 这是最容易踩的坑。

**多等位基因的 context**（官方 `-pmhc -context` 在此发行版中有 bug，用包装器）：

```bash
cat > ctx_mhc.txt <<'EOF'
SLYNTVATL AASLYNTVATLA HLA-A02:01
SLYNTVATL AASLYNTVATLA HLA-A01:01
EOF

netMHCpan_ctx -f ctx_mhc.txt
```

## 2. NetChop 3.1d —— 蛋白酶体切割位点预测

预测蛋白在蛋白酶体中被切在哪里，用于判断某个肽段是否**真的能被切出来**。

### 2.1 基本用法

```bash
cat > prot.fsa <<'EOF'
>test_protein
MLLSVPLLLGLLGLAVGQCSVSWQPPPEKLLSEEDL
EOF

netchop prot.fsa
```

### 2.2 两个模型：`-v 0` / `-v 1`

| 参数 | 模型 | 用途 |
|---|---|---|
| `-v 0` | C 端切割（Cterm 3.0） | **默认**，常规预测 |
| `-v 1` | 20S 蛋白酶体 | 模拟组成型蛋白酶体 |

两者结果**确实不同**（实测同一蛋白，Cterm 判定 18 个切割位点，20S 判定 14 个，且位置不完全一致）。按实验体系选择。

### 2.3 其它参数

| 参数 | 作用 |
|---|---|
| `-t 0.5` | 切割阈值（默认 0.5），调高更严格 |
| `-s` | 短格式输出 |
| `-verbose` | 详细输出 |

### 2.4 输出怎么读

```
   1   M  S   0.614613 test_prote
   4   S  .   0.024125 test_prote
```

| 列 | 含义 |
|---|---|
| 位置 | 残基序号 |
| 残基 | 氨基酸 |
| `S` / `.` | **S = 切割位点**，`.` = 不切 |
| 数值 | 切割概率（0–1） |

## 3. NetMHCstabpan 1.0 —— 呈递稳定性 / 半衰期

预测肽-MHC 复合物的**半衰期**，即呈递到细胞表面后能维持多久。结合亲和力高但半衰期短的肽，实际呈递效果差。

### 3.1 基本用法

```bash
netMHCstabpan -a HLA-A02:01 -p pep.txt
```

### 3.2 加亲和力列（`-ia`）

```bash
netMHCstabpan -ia -a HLA-A02:01 -p pep.txt
```

> 本机已配好兼容层，`-ia` 可直接用，无需额外安装 NetMHCpan-2.8。

### 3.3 输出怎么读

不加 `-ia`（8 列）：

```
 pos   HLA         peptide    Identity    Pred   Thalf(h)  %Rank_Stab  BindLevel
   0  HLA-A*02:01  SLYNTVATL  PEPLIST    0.837    3.90       0.90      <= WB
```

| 列 | 含义 |
|---|---|
| `Pred` | 稳定性得分 (0–1) |
| `Thalf(h)` | **预测半衰期（小时）** ← 核心指标 |
| `%Rank_Stab` | 稳定性百分位（越小越稳定） |

加 `-ia` 后额外 5 列：`1-log50k`、`Aff(nM)`、`%Rank_aff`、`Combined`、`Combined_%rank`。
`Combined` 是稳定性与亲和力的加权综合，`-waff 0.8` 可调亲和力权重。

### 3.4 注意

- `-p` 肽段输入、`-f`/位置参数 FASTA 输入
- `-s 0/1/2` 排序（稳定性 / 亲和力 / 综合）；实测本例 3 条肽排序结果相同（得分差异小），差异在数据量大的时候才明显

## 4. 三步串联：完整呈递通路预测

这是三个软件最典型的组合用法 —— 一条蛋白走完"能不能被切出来 → 能不能结合 → 呈递稳不稳"。

```bash
#!/usr/bin/env bash
# pipeline.sh  用法: bash pipeline.sh protein.fsa HLA-A02:01
set -euo pipefail
PROT=$1; ALLELE=$2
OUT=./result; mkdir -p "$OUT"

# 第 1 步：NetChop —— 找蛋白酶体切割位点
netchop -v 0 "$PROT" > "$OUT/1_chop.txt"

# 第 2 步：从切割位点生成候选肽（9mer，末端落在 S 位点）
python3 - "$PROT" "$OUT/1_chop.txt" > "$OUT/2_peptides.txt" <<'PY'
import sys
prot = ''.join(l.strip() for l in open(sys.argv[1]) if not l.startswith('>'))
sites = {int(l.split()[0]) for l in open(sys.argv[2])
         if l.strip() and not l.startswith('#') and len(l.split()) > 2 and l.split()[2] == 'S'}
for end in sites:
    start = end - 9
    if start >= 0:
        print(prot[start:end])
PY

# 第 3 步：NetMHCpan —— 结合预测
netMHCpan -a "$ALLELE" -p "$OUT/2_peptides.txt" -BA > "$OUT/3_binding.txt"

# 第 4 步：NetMHCstabpan —— 稳定性
netMHCstabpan -ia -a "$ALLELE" -p "$OUT/2_peptides.txt" > "$OUT/4_stability.txt"

echo "完成，结果在 $OUT/"
grep -E '<= (SB|WB)' "$OUT/3_binding.txt" | head
```

实测（27 aa 蛋白 → HLA-A02:01）：切出 28 条候选 9mer，其中 2 条为结合肽（`MLLSVPLLL` %Rank 0.144、`GLAVGQCSV` %Rank 0.152）。

## 5. 常见问题

| 现象 | 原因 | 解决 |
|---|---|---|
| `Error. MHC name HLA-A*02:01 ... cannot be found` | 等位基因**带星号** | 去掉星号写成 `HLA-A02:01` |
| `-context` 静默返回 0 行 | 上下文长度不是 12 | 用 9mer 肽 + 3 残基侧翼 = 12 |
| `Wrong line format PRDLIST_READ` | 用了官方 `-pmhc -context` | 改用 `netMHCpan_ctx -f file` |
| `Error. Cannot make tmpdir` | TMPDIR 指向不存在目录 | 本机已修好；若自定义请建目录 |
| `Unable to open $NETMHCpan/data/version` | 绕过启动器直接调二进制 | 用 `netMHCpan` 启动器，别直接调 `Linux_x86_64/bin/` 里的 |
| 从 `/mnt/c/` 跑很慢 | Windows 目录 I/O | 把数据复制到 `~/work` 再跑 |

## 6. 速查表

```bash
# NetMHCpan
netMHCpan -a HLA-A02:01 -p peptides.txt                  # 基础预测
netMHCpan -a HLA-A02:01 -f protein.fsa                   # 蛋白滑窗
netMHCpan -a HLA-A02:01,HLA-A24:02 -p peptides.txt -BA   # 多等位基因 + 亲和力
netMHCpan -listMHC | grep '^HLA-A02'                     # 查等位基因名
netMHCpan_ctx -f context_mhc.txt                         # 多等位基因 context

# NetChop
netchop protein.fsa                                      # 默认 Cterm
netchop -v 1 protein.fsa                                 # 20S 蛋白酶体
netchop -t 0.9 protein.fsa                               # 更严格阈值

# NetMHCstabpan
netMHCstabpan -a HLA-A02:01 -p peptides.txt              # 半衰期
netMHCstabpan -ia -a HLA-A02:01 -p peptides.txt          # 加亲和力列
```
