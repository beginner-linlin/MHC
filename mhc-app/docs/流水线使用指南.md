# MHC 预测工作台 · 本地流水线使用指南

设计书十步路线（①数据获取 → ⑥新抗原预测）中「上游生信」部分的本地执行手册。
脚本目录：`/opt/bio/app/pipeline/`，总控入口 `run_all.sh`。

```
①数据获取(GDC) → ②质控比对(fastqc/trimmomatic/bwa) → ③突变检出(MuTect2|Strelka2 + snpEff)
      → ④表达定量(STAR+RSEM) → ⑤HLA分型(OptiType) → ⑥提取突变+交工作台预测
```

---

## 0. 一句话总控

```bash
WSL 内执行：
bash /opt/bio/app/pipeline/run_all.sh \
  --fastq tumor_R1.fq.gz --fastq2 tumor_R2.fq.gz \
  --normal-fastq normal_R1.fq.gz --normal-fastq2 normal_R2.fq.gz \
  --alleles "HLA-A02:01,HLA-B07:02"
```

- 不传 `--alleles` 时会先跑 ⑤ OptiType 自动分型（需要 WES 比对完成）。
- `--start/--stop` 断点续跑；`--dry-run` 只打印将要执行的命令；`--force` 忽略已有检查点。
- 单步执行：`bash /opt/bio/app/pipeline/30_align.sh --work <目录>` 等。

## 1. 参考基因组（一次性）

```bash
bash /opt/bio/app/pipeline/10_prepare_ref.sh ~/mhc-pipeline/ref
# 表达定量还需 STAR 索引（内存 ≥32GB，耗时较长）：
WITH_STAR=1 bash /opt/bio/app/pipeline/10_prepare_ref.sh ~/mhc-pipeline/ref
```

Ensembl GRCh38 release-113 primary assembly（~3.1GB）+ BWA index + samtools faidx + GATK dict。GTF 一并下载（RSEM 需要）。磁盘需求约 20GB。

## 2. GATK4（MuTect2 体细胞突变检出）

流水线以 **MuTect2 优先，Strelka2 兜底**。GATK 为单个大 jar（~700MB），两种装法：

```bash
# 装法 A：GitHub release（官方，文件大）
cd /root/mhc_inst
curl -fL --retry 3 -o gatk.zip https://github.com/broadinstitute/gatk/releases/download/4.6.1.0/gatk-4.6.1.0.zip
unzip gatk.zip -d /opt/bio/tools/
ln -sf /opt/bio/tools/gatk-4.6.1.0/gatk /opt/bio/tools/bin/gatk

# 装法 B：Maven Central 单 jar（更小，~250MB）
curl -fL -o /opt/bio/tools/gatk-package-local.jar \
  https://repo1.maven.org/maven2/org/broadinstitute/gatk/4.6.1.0/gatk-package-4.6.1.0-local.jar
cat > /opt/bio/tools/bin/gatk <<'EOF'
#!/bin/bash
exec java -Xmx4g -jar /opt/bio/tools/gatk-package-local.jar "$@"
EOF
chmod +x /opt/bio/tools/bin/gatk

# 验证
gatk --version
```

依赖 Java 17（已随 openjdk-17 安装）。下载慢时可先跳过——流水线检测到无 GATK 时提示改用 Strelka2。

## 3. Strelka2（兜底突变检出器）

Strelka 2.9.10 官方包基于 **Python 2**。Ubuntu-24.04 无 python2，官方 configure 脚本直接跑会报 `env: 'python2'`。

- 推荐路径：**优先装 GATK（第 2 节）**，Strelka2 可不装。
- 若坚持装 Strelka2：安装 python2（`apt install python2` 若可用）或改用兼容层后：

```bash
ln -sf /opt/bio/tools/strelka-2.9.10.centos6_x86_64/bin/configureStrelkaSomaticWorkflow.py \
       /opt/bio/tools/bin/configureStrelkaSomaticWorkflow
```

工作台「数据准备 → 在线检测」会显示当前状态。

## 4. OptiType（HLA-I 分型）

已部署：`/opt/bio/tools/OptiType`（官方 2.x，src 布局）+ venv `/opt/bio/tools/optitype-venv`。

```bash
# 运行方式（流水线内部同款）：
PYTHONPATH=/opt/bio/tools/OptiType/src /opt/bio/tools/optitype-venv/bin/python -m optitype --version

# ILP 求解器：需要 cbc
which cbc || apt-get install -y coinor-cbc
```

依赖：numpy/pandas/pysam/click/pyarrow/pyomo/matplotlib（venv 内已装或按报错补装）。
参考库：OptiType 自带 HLA-I 参考集（`data/`），首次分型无需联网。

## 5. VEP / snpEff（突变注释）

流水线优先 **snpEff**（apt 直装，`GRCh38.105` 数据库首次运行自动 `-download`）：

```bash
snpEff -version
# 数据库手动预下载（可选）：
snpEff download -v GRCh38.105
```

Ensembl VEP 在 Ubuntu-24.04 官方源不可用（需 conda/bioperl 深度依赖），默认不装；流水线 `50_annotate.sh` 按 `require_annotator` 自动选择可用者。

## 6. 数据准备（TCGA-PAAD）

见工作台「数据准备」面板的 TCGA 下载指引（GDC 门户 → WXS/RNA-Seq → manifest → `gdc-client download -m manifest`）。
已有突变数据（MAF/VCF）的用户可跳过 ②③④⑤，直接从 `80_extract_mutations.sh` 或工作台「突变肽筛选」模式开始。

## 7. 输出与交接

流水线 ⑥ 产物（`~/mhc-pipeline/work/`）：

| 文件 | 内容 |
| --- | --- |
| `mutations.tsv` | 错义突变（蛋白/位置/原 AA/新 AA/上下文 21-mer） |
| `proteins.fasta` | 突变蛋白序列（可直接贴进工作台「突变肽筛选」） |
| `neoantigen.json` | 组装好的预测任务（等位基因、肽长、突变列表） |
| `90_result/summary.tsv` | NetMHCpan 全流程预测结果（含 SB/WB/稳定性） |

也可直接运行 `90_neoantigen.sh` 把 `neoantigen.json` 交给工作台后端跑完整预测。
